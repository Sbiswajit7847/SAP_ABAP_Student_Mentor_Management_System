SAP ABAP ALV Student Report
 
## Project Overview
 
This project is an SAP ABAP ALV report developed to display student and mentor information in a structured and user-friendly format.
 
The program retrieves student information based on the entered Student USN, retrieves the corresponding mentor information, processes the data using internal tables, and displays the final result using the ALV Grid.
 
## Key Features
 
* Student USN-based data selection
* Student information retrieval
* Mentor information retrieval
* Data processing using internal tables
* ALV Grid display
* Custom ALV field catalog
* Selection screen with mandatory Student USN
* Database access using Open SQL
 
## ABAP Concepts Used
 
* ABAP Dictionary
* Internal Tables
* Work Areas
* Open SQL
* `SELECT-OPTIONS`
* `FOR ALL ENTRIES`
* `READ TABLE`
* `SORT`
* `LOOP AT`
* ALV Field Catalog
* `REUSE_ALV_GRID_DISPLAY`
 
## Output
 
The report displays:
 
* Student USN
* Student Name
* Student Address
* Student Mobile
* Student Branch
* Mentor Number
* Mentor Name
